# Data provenance

Original answerable questions, answer spans and passages come from the official
[SQuAD 2.0 training dataset](https://rajpurkar.github.io/SQuAD-explorer/).
The source is pinned to SHA-256
`68dcfbb971bd3e96d5b46c7177b16c1a4e7d4bdef19fb204502738552dede002`.
SQuAD data and derivatives are under CC BY-SA 4.0; this includes the reviewed
context-removal annotations, answer aliases and retained-fact control questions.
Raw passages and materialized datasets are kept under ignored artifacts/.

Review annotations and additional control questions are AI-assisted work by
Codex for this project, not new independent human gold. The code retains the
repository's MIT license. Do not interpret the code license as relicensing data.
